# Title
Student Society Event Planner group project

## Description
This project showcases 2 seperate algorithms for our event planning scenario in which activities will be chosen attempting to maximise the enjoyment value based of our budget constraint by calculating the best possible combination of activities that fit into the set budget.

### Installing
To install this program ensure you extract the zip file and open the ECM1414 folder in your IDE.

### Executing program
To execute the program, head to the performance_test.py file and define the pointer to the input file you want to test,
this will look like:
#input_file = '/Sample Input Files-20260120/input_medium.txt'
for the sample tests, here you only need to change the 'input_medium.txt' to the txt file of the fileset you want to test, for the custom tests change the 'Sample Input Files-20260120' to custom_tests and then change the txt file to the desired filename.
After you have specified your input file simply run the performance_test.py python file and this will run both algorithms on the input.
