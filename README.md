# Title
Student Society Event Planner group project

## Description
This project showcases 2 seperate algorithms for our event planning scenario in which activities will be chosen attempting to maximise the enjoyment value based of our budget constraint by calculating the best possible combination of activities that fit into the set budget.

### Installing
This program is self contained and requires no dependencies. Once extracted from its zip file, run the commands in the next section in the extracted directory.

### Executing program
To run the program, use `python3 run_comparison.py 'file_path.txt'`.
University provided tests are in "Sample Input Files-20260120"
Our custom tests are in "custom_tests"

Ensure to include a starting forward slash: /
E.g `python3 run_comparison.py '/Sample Input Files-20260120/input_small.txt'`
