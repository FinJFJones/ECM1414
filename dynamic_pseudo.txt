Function add activity:
	For budget from 0 to max budget:
		If there is budget remaining:
			Inclusion score = enjoyment of current activity + max enjoyment of activities in remaining budget 
			If inclusion score > current max enjoyment:
				Add activity and remove from budget
			Else:
				Keep previous activities
		Else:
			Keep previous activities
	Return enjoyment of chosen activities

Function dynamic algorithm:
	Table = grid for each activity, activity cost
	For each activity recorded:
		Table = table + current activity, activity cost
	Return final entry in table
