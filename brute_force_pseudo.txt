Function best activity(activities, number of activities, current activities, max cost):
    top activity = current activities 
    For activity in activities:
         If activity in current activities:
              Continue

  	 new set = current activities + activity

         If cost of new set > max cost:
              Continue

         found activity = best activity(activities, number of activities, new set, max cost)

         If enjoyment of found activity > enjoyment of top activity:
              top activity = found activity

    Return top activity

Function brute force(activities, number of activities, max time, max cost):
    Return best activity(activities, number of activities, empty list, max cost)
